# Φθηνό Πλάνο Γευμάτων – εφαρμογή για κινητό

Εβδομαδιαίο πλάνο γευμάτων με τις προσφορές της Lidl, το πιο φθηνό δυνατό:
πρωινό & βραδινό τοστ ή κορνφλέικς, φρούτο για δεκατιανό, μεσημεριανό σε 1–3 μαγειρέματα
την εβδομάδα, λίστα αγορών με τσεκάρισμα και PDF.

Δουλεύει σε Android και iPhone, μπαίνει στην αρχική οθόνη με εικονίδιο, και ανοίγει και χωρίς ίντερνετ.

## Πώς δουλεύει

| Κομμάτι | Τι κάνει |
|---|---|
| `scraper.py` | Διαβάζει τις προσφορές από το lidl-hellas.gr και τις γράφει στο `docs/offers.json` |
| `.github/workflows/update-offers.yml` | Τρέχει το `scraper.py` αυτόματα κάθε πρωί στις 07:00 (δωρεάν, στο GitHub) |
| `docs/` | Η εφαρμογή. Το GitHub Pages τη δημοσιεύει δωρεάν |
| `docs/data.js` | Συνταγές, υλικά, φρούτα, εκτιμώμενες τιμές – εδώ προσθέτεις φαγητά |

## Εγκατάσταση (μία φορά, ~10 λεπτά)

1. Φτιάξε δωρεάν λογαριασμό στο https://github.com/signup
2. Πάτα **New repository** (πάνω δεξιά, το **+**). Όνομα: `plano`, επίλεξε **Public**, πάτα **Create repository**.
3. Στη σελίδα που ανοίγει πάτα **uploading an existing file**. Σύρε μέσα **όλο το περιεχόμενο** αυτού του φακέλου
   (τους φακέλους `docs` και `.github`, και τα αρχεία `scraper.py`, `README.md`). Πάτα **Commit changes**.
4. **Settings → Pages**: στο *Branch* διάλεξε `main` και φάκελο `/docs`, πάτα **Save**.
   Σε 1–2 λεπτά η εφαρμογή είναι στο `https://<το-όνομά-σου>.github.io/plano/`
5. **Actions** → αν ζητήσει, πάτα **I understand… enable them**. Μετά **Ενημέρωση προσφορών Lidl → Run workflow**
   για να δεις ότι δουλεύει η αυτόματη ενημέρωση (πράσινο ✓).
   Αν βγει κόκκινο με μήνυμα για *permission*: **Settings → Actions → General → Workflow permissions →
   Read and write permissions → Save** και ξανά *Run workflow*.

## Στο κινητό

Άνοιξε τη διεύθυνση `https://<το-όνομά-σου>.github.io/plano/` και:

- **Android (Chrome):** μενού ⋮ → **Εγκατάσταση εφαρμογής** (ή *Προσθήκη στην αρχική οθόνη*)
- **iPhone (Safari):** κουμπί κοινοποίησης □↑ → **Προσθήκη στην οθόνη Αφετηρίας**

Το κουμπί **PDF** στην εφαρμογή ανοίγει την εκτύπωση: διάλεξε *Αποθήκευση ως PDF*.

## Καλό να ξέρεις

- Αν κάποια μέρα η Lidl δεν αφήσει το GitHub να διαβάσει τη σελίδα, η εφαρμογή κρατάει τις
  τελευταίες προσφορές που ξέρει (φαίνεται η ημερομηνία πάνω-πάνω) και για τα υπόλοιπα βάζει εκτιμώμενες τιμές.
- Οι τιμές «Εκτίμηση» είναι κατά προσέγγιση – άλλαξέ τες στο `docs/data.js` αν θέλεις.
- Τα τσεκαρίσματα της λίστας αγορών μένουν μόνο στο κινητό σου.
